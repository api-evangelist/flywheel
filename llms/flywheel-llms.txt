# Flywheel

> Flywheel is a medical imaging data management and AI development platform for biomedical research, clinical trials, and medical device R&D. It organizes imaging data (DICOM, NIfTI, and more) in a strict container hierarchy, automates processing with reusable "Gears," and exposes a per-instance REST API consumed through an official Python SDK, CLI, and Developer Toolkit. Flywheel is HIPAA, SOC 2/SOC 3, GDPR, and 21 CFR Part 11 compliant.

This llms.txt was generated by the API Evangelist enrichment pipeline from the repository's apis.yml and captured artifacts (method: generated). The Flywheel REST API is served per customer instance at <instance>/api with interactive Swagger at <instance>/api/docs.
